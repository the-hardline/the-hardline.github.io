Private Mail Assistant

A private assistant for one person.

Private Mail Assistant is a self-hosted tool used by its owner alone. It is not a public service, and no one else can sign in to it or connect an account.

What it does with Google data

With the owner's permission, it connects to the owner's own Gmail account through the Gmail API to help the owner keep track of and manage their mail. It never reads any mailbox but the owner's own.

How that data is handled is set out in the privacy policy.
